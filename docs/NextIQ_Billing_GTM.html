1. Executive Summary

NextIQ is Nextiva's AI-powered agent intelligence engine, available as an add-on module across all NEXT platform plans. NextIQ provides real-time intent classification, knowledge base responses, Next Best Action recommendations, and fully autonomous Autopilot capabilities — all designed to reduce handle time, increase first-contact resolution, and drive revenue through intelligent upsell detection.

Billing is based on WorkItem-level consumption: every time NextIQ's AI services are used within a WorkItem (a customer interaction session), it counts as one NextIQ unit — regardless of how many AI calls, KB lookups, or tool executions happen within that session. This makes pricing simple, predictable, and directly tied to business value.

2. How NextIQ Billing Works

The NextIQ Unit

1 NextIQ Unit = AI services consumed within 1 WorkItem.
A WorkItem is a runtime session initiated by a customer request (inbound) or an agent-initiated outbound interaction. If NextIQ is invoked at any point during that WorkItem — whether for a single KB lookup or a multi-step Autopilot flow — it counts as exactly one unit.

Key Billing Principles

Principle Description
One WorkItem = One Unit No matter how many AI calls happen inside a WorkItem — KB lookup, 3 NBA generations, 2 tool executions, Autopilot actions — it is billed as a single unit.
No NextIQ = No Charge If a WorkItem completes without any NextIQ AI service being invoked, no unit is consumed.
Transfer-Safe If a WorkItem is transferred between agents, it remains the same WorkItem and is counted only once.
Channel-Agnostic The same billing applies whether the WorkItem originated from voice, chat, email, SMS, or social.

4. What Counts as a NextIQ Unit

A NextIQ unit is consumed when any of the following AI services are invoked during a WorkItem. All activity within a single WorkItem rolls up into one unit.

📚 Knowledge Base Response
Intent classification, KB article retrieval, confidence scoring, and AI-generated contextual answers.
🎯 Next Best Actions
NBA generation, reply suggestions, greeting templates, and action recommendations based on conversation context.
⚡ Tool / Action Execution
Function calls triggered by NBA actions — checking billing, processing refunds, scheduling meetings, API lookups, etc.
🤖 Autopilot Mode
Autonomous decision-making, multi-step execution, countdown-gated actions — all within the same WorkItem unit.

Example: An agent handles a billing dispute WorkItem. NextIQ classifies intent (1 AI call), retrieves a KB article about refund policy (2nd call), generates 3 NBAs (3rd call), the agent executes "Check Transaction" tool (4th call), then executes "Process Refund" tool (5th call). Total billed: 1 NextIQ unit.

How Deduplication Works

The Metering Service ensures each WorkItem is counted only once. When the NextIQ Engine is first invoked during a WorkItem, it emits a nextiq.session.start event tagged with the WorkItem ID. Subsequent AI calls within the same WorkItem are tracked for analytics but do not increment the billing counter. The unit is finalized when the WorkItem closes.

6. Overage Handling — Recommended Options

When a customer exhausts their included free units (or add-on allotment), we need a clear overage strategy. Three options are presented below for decision.

  Option A: Auto-Charge Option B: Soft-Block + Upsell Option C: Grace Buffer + Block
How It Works Usage continues seamlessly. Overage units billed at a per-unit rate (e.g., $0.10/unit) on the next invoice. NextIQ features are soft-disabled. Agents see a banner prompting the admin to purchase additional units or upgrade. A 10% grace buffer is provided above the limit. Admin is notified. After grace is exhausted, NextIQ is soft-disabled with an upgrade CTA.
Pros Zero disruption to agent workflow. Revenue upside on high-usage accounts. Simple to implement. No surprise charges. Creates natural upgrade moment. Admin retains cost control. Best of both worlds: avoids abrupt cutoff (grace period) while preventing bill shock. Good adoption signal.
Cons Risk of "bill shock." Requires clear consent mechanism. May create billing disputes. Disrupts agent experience mid-shift. Could frustrate frontline teams. Lost AI value during block period. Slightly more complex to implement and explain. Grace buffer percentage needs tuning.
Best For Enterprise customers, high-trust accounts, consumption-oriented buyers. Cost-sensitive SMBs, customers new to AI features, risk-averse admins. Mid-market customers who want predictability without abrupt disruption.

Recommendation: Default to Option C (Grace Buffer) for Launch and Growth plans, with Option A available as an opt-in for Enterprise customers who prefer uninterrupted service. All plans should send admin notifications at 80% and 100% usage thresholds.

7. Agent Experience on Unit Exhaustion

When free units are fully consumed and the admin has not purchased the add-on, the NextIQ Intelligence panel collapses to a compact paused-state card. Non-AI tabs remain fully operational.

What the Agent Sees

The NextIQ Intelligence tab collapses to a compact card (~200px) containing:

  • “Intelligence Paused” header with NextIQ logo
  • Usage context: “Your team used all 50 free NextIQ units this month.”
  • Auto-generated value summary (e.g., interactions assisted, AHT reduction, upsells surfaced)
  • “Request Upgrade” button (notifies admin via in-app + email)
  • “Dismiss” button (hides card for session; orange tab badge persists)

An orange badge appears on the NextIQ tab icon, visible across all tabs, persisting until units are restored.

Autopilot Edge Case

If Autopilot is active when units run out mid-WorkItem, it completes the current WorkItem (already metered) but deactivates for subsequent WorkItems. The toggle moves to OFF and becomes non-interactive. A one-time toast appears: “Autopilot paused — free NextIQ units exhausted for this billing cycle.”

Admins need clear visibility into NextIQ consumption to manage costs and understand value. The NextIQ Usage Dashboard (accessible from Admin → Billing) will provide:

📊 Current Period Usage
Progress bar showing units consumed vs. allotment. Updated in near real-time. Color-coded: green (under 60%), amber (60-80%), red (80%+).
👥 Per-Agent Breakdown
Table showing units consumed per agent, sortable by usage. Helps identify heavy users and training opportunities.

30-day rolling chart of daily NextIQ units consumed. Shows adoption trajectory and seasonal patterns.
🔔 Threshold Alerts
Automated email + in-app notifications at 80% usage (warning) and 100% usage (action required). Configurable by admin.

Value Metrics (alongside usage)

To justify the add-on cost, the dashboard will also surface outcome metrics tied to NextIQ usage:

  • Average Handle Time (AHT) delta — comparison for WorkItems with vs. without NextIQ

  • Autopilot resolution rate — percentage of WorkItems fully resolved by Autopilot with no agent intervention
  • Upsell / cross-sell detections — count of revenue opportunities surfaced by NextIQ NBAs

10. Frequently Asked Questions

Q: Does a transferred WorkItem count as two units?
No. A WorkItem maintains the same ID across transfers. It is billed as one unit regardless of how many agents handle it.
Q: What if NextIQ is never used during a WorkItem?
No unit is consumed. Billing only occurs when at least one NextIQ AI service is invoked within the WorkItem.
Q: If Autopilot runs 6 actions in one WorkItem, is that 6 units?
No. All AI activity within a single WorkItem — whether 1 action or 20 — counts as one unit.
Q: Are the free units per-seat or per-account?
Free units are per-account per billing cycle. A Launch account gets 50 total units shared across all agents, not 50 per agent.
Q: Do free units roll over to the next month?
No. Unused free units expire at the end of each billing cycle.
Q: Can customers buy additional unit packs without upgrading their plan?
Yes (recommended). We plan to offer unit top-up packs (e.g., 500 units for $X) purchasable from the Admin billing page. This is a revenue expansion lever for Launch and Growth customers.
Q: How does NextIQ billing interact with the Actions Builder?
Actions built in the Actions Builder are tools available to the NextIQ engine. When an action is executed within a WorkItem, it is part of that WorkItem's single unit. Building and configuring actions in the Actions Builder does not consume units.
Q: Is there a per-seat minimum for the add-on?
The $10/seat add-on applies to every seat on the account. There is no option to enable it for individual agents — it is an account-wide module.
Q: What channels are supported?
NextIQ is channel-agnostic. It works across voice, chat, email, SMS, and social. All channels use the same WorkItem-based billing model.

9. Voice Channel Adaptation

NextIQ is an omnichannel assistant. In voice channels, the AI intelligence (intent classification, KB, NBAs) remains identical — only the UI interaction layer changes. The core principle: NextIQ assists the agent's brain, not the agent's keyboard.

Chat vs. Voice — Feature Comparison

Team Chat — Persistent Bottom Drawer

A collapsible Team Chat drawer sits at the bottom of the NextIQ right panel, independent of which tab (Intelligence, Customer 360, Notes, etc.) is active. This enables real-time agent-to-supervisor collaboration without leaving the AI assistance view.

  • Collapsed: Thin 36px bar showing “Team — 2 unread” with an expand chevron.
  • Expanded: Slides up to ~40% of the right panel. Shows a threaded chat with supervisor context (e.g., “Emily Davis called in — check if domain changed”) and an input bar.
  • Distinction from Internal Notes: Internal Notes are async, WorkItem-scoped annotations. Team Chat is real-time, people-scoped messaging.
ⓘ Implementation Note
Channel detection is driven by the channel property on each conversation/engagement (e.g., 'phone', 'chat', 'email', 'sms'). The intelligence engine (intent classification, KB retrieval, NBA generation) is completely channel-agnostic — only the UI rendering layer adapts.
